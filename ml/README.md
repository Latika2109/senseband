# ML (Milestone 5)

```
senseband_features/   ONE feature implementation, used by training AND the edge (no train/serve skew)
senseband_train/      datasets (download/extract/loaders), training, ONNX export, metrics, latency bench
models/               *.onnx + metrics.json + METRICS.md   (generated by `make train`)
tests/                feature + training + metrics-contract tests
```
`make train` downloads UCI HAR, PAMAP2 and PhysioNet CinC 2017 (≈ 1 GB, safely extracted into `ml/data/`, git-ignored),
trains all five models with subject-wise cross-validation, exports ONNX, checks ONNX-vs-LightGBM parity, size (< 5 MB) and
latency, and writes `models/metrics.json` + `METRICS.md`. `make bench` re-times the models; run it **on the Pi 3**.

The trained `.onnx` files are git-ignored (they are build artifacts): run `make train`, or copy `ml/models/` from a release onto the band.

## Results (this repo, subject-wise CV, laptop)
See `models/METRICS.md` for the generated table. Honest summary:

| model | data | result | target | met |
|---|---|---|---|---|
| M1 activity & posture | UCI HAR + PAMAP2 (real, 39 people) | macro-F1 **0.851** (rules: 0.731) | ≥ 0.90 | **no** (sitting/standing ≈ 0.77–0.80) |
| M2 fall | **simulated only** | sensitivity 1.00 (simulated) | ≥ 0.95 | **not validated** – SisFall unreachable; disabled on the edge |
| M3 ECG quality | CinC 2017 noisy vs readable + simulated unusable | accuracy **0.957** | ≥ 0.92 | yes (CinC 2011 unreachable; 2017 'noisy' used as proxy) |
| M4 rhythm (possible AF) | CinC 2017 (real) | AF F1 **0.741** (old RR rule: 0.27) | ≥ 0.80 | **no** |
| M5 expected HR | PAMAP2 (real, 9 people) | MAE **11.9 → 10.1 bpm** after personalisation | ≤ 8 | **no** |

Gaps and next steps: M1 needs more waist-worn data with sitting/standing diversity and real running; M4 needs ECG morphology
(P-wave/f-wave) features beyond RR timing or a small 1-D CNN; M5 needs a larger population (PAMAP2 has 9 people and
constant time-of-day) and the 48 h personalisation tuned on real wear data; M2 needs real fall data before it may be enabled.
Do not tune hyper-parameters on the same folds you report: collect new subjects instead.

## Edge integration
`edge/senseband_edge/models/registry.py` loads each ONNX model only if onnxruntime is installed, the metrics entry matches
`FEATURE_VERSION`, the file is < 5 MB and (for M2) `models.fall.enabled` is true; a model that errors or averages > 50 ms is
switched off at run time. Every model has a rule-based fallback, so the band works with no models at all.
Changing any feature function = bump `FEATURE_VERSION` and retrain (the edge refuses a mismatch).
